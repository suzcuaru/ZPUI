## 3. Починка модуля трафика (терабайты, GB/s)
Причины: (а) суммировались счётчики с момента загрузки Windows по всем не-loopback интерфейсам, включая WAN-miniports и WSL/Hyper-V vSwitch → «терабайты»; (б) при сбросе счётчиков интерфейса (сон, VPN, перезапуск WSL) дельта uint64 уходит в астрономию → «скорость в гигабайтах».
Фикс в `monitor/traffic.go`:
- фильтр интерфейсов: только Up, не loopback, с физическим адресом;
- per-interface дельты с guard'ом (интерфейс не был в прошлой выборке или счётчик уменьшился → только ре-базлайн, без дельты);
- итоговые байты = накопитель за сессию ZPUI (запуск с нуля), скорости = дельта/время. Поля API не меняются; в отчёте «Traffic Summary» значения станут адекватными.
