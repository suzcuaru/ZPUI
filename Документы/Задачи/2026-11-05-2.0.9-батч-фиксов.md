# Батч фиксов 2.0.9: тумблеры тиров, python-окно, запуск в трей, мёртвое окно автостарта, чистка/оптимизация

## Проблема

1. **Тумблеры тиров A–D (меню «Отображение стратегий»)** — дефолт перевёрнут:
   `web/src/components/zapret/StrategiesTab.jsx:111` — `TIER_TOGGLES_DEFAULT = {a:false, b:false, c:true, d:true, untested:true}` (владельцу нужно: только A и B). Выбор пользователя пишется только в localStorage WebView2 (`StrategiesTab.jsx:306-312`), слой config.json отсутствует (нет поля в `internal/config`, нет ветки в GetConfig/SetConfig) — профиль `%APPDATA%\<имя exe>` привязан к имени бинарника и стирается чистой переустановкой (`internal/pkginst/pkginst.go:624-632`), поэтому выбор «слетает».
2. **Видимое python-окно при запуске** — цепочка спавна в Go полностью скрыта (`internal/tgproxy/manager.go:184` → `executil.HiddenCmd`, флаги корректны, `internal/executil/exec_windows.go:19-26`), но `ZPUI-TgProxy.exe` собран как консольный (`../ZPUI-TgProxy/integration/tgproxy.spec:67` `console=True`) — единственное оставшееся окно возможности, плюс у владельца могла стоять промежуточная сборка от 18:43 04.11.
3. **«Запуск свёрнутым» не скрывает окно** — `web/src/components/StartupScreen.jsx:485` безусловно вызывает `runtime.WindowShow()` при каждом монтировании стартового экрана (рендерится на каждом запуске, `App.jsx:98,931-940`), в обход бэкенд-флага `windowVisible` (`internal/app/app.go:307`) — окно «прорывается» из `--hidden`.
4. **После автозапуска с системой окно не функционирует** — следствие п.3: окно физически видно, но `windowVisible=false` и `winVisible.shown=false` → `isInteractive()===false` навсегда; `pollStatus` (`App.jsx:592-593`), `usePolling`, `useNow` заглушены. Переоткрытие из трея идёт через `App.ShowWindow()` (`internal/app/app_window.go:49-59`: emit `window:shown` + флаг + WindowShow) — потому «закрыть и открыть помогает». Сопутствующее: `pkginst.LaunchApp` (`pkginst.go:966-975`) стартует ZPUI.exe без аргументов — после установки окно всегда показывается.
5. **Чистка/оптимизация** — аудит 05.11: мёртвые биндинги App (9), мёртвые экспорты пакетов (~20), мёртвые маршруты api.js, 3 осиротевших i18n-ключа; фоновые циклы без `power.Stretch` (`internal/app/app_server.go:96-112`, `internal/app/traffic_history.go:59`); фронт: поллер туннеля `ProfileDrawer.jsx:1002` без гейта открытости (20с, сетевой REST), devices-поллер MonitorPage 5с (каждый тик спавнит `arp -a`), два 5с-поллера ProxyPage, `/api/versions` 10с на статике.

## Цель

Корректные дефолты и стойкая персистентность фильтра стратегий; ни одно окно не мелькает при старте; «Запуск свёрнутым» реально скрывает окно на всех путях запуска; окно после автозапуска работает с первого открытия; лишний код удалён, фоновая активность снижена.

## Требования

- R1. Дефолт тумблеров тиров: включены только A и B (`{a:true, b:true, c:false, d:false, untested:false}`); тир S виден всегда (без изменений).
- R2. Выбор пользователя — единственный источник истины `config.json` (поле `strat_tier_toggles`), сохраняется через `/api/config`; одноразовая миграция из localStorage при первом чтении; после переустановки/смены бинарника выбор сохраняется.
- R3. `ZPUI-TgProxy.exe` собирается windowed (`console=False`, диалоги traceback подавлены) — не может создать консоль ни при каком спавне.
- R4. Старт с `--hidden` (тумблер «Запуск свёрнутым»): окно не показывается ни одним путём (стартовый экран — через бэкенд-гейт); обычный старт — окно выводится наверх как раньше.
- R5. Все пути показа/скрытия окна идут через бэкенд (флаг `windowVisible` не расходится с реальностью); новый биндинг `POST /api/app/request-show`: при скрытом старте — no-op, иначе — штатный показ.
- R6. `pkginst.LaunchApp` учитывает `start_minimized` (после установки/обновления окно показывается только при выключенном тумблере).
- R7. После показа окна из трея при автозапуске данные загружаются без переоткрытия: гейт снимается, немедленный догоняющий тик (механизм `onWindowShownChange` уже есть), плюс самопроверка `is-shown` после завершения стартового экрана.
- R8. Удалить проверенно мёртвый код (список в «Плане»), сохранив: семью устройств из БД (задел под страницу «Устройства»), `GetAutostartStatus`, `ApplyUpdate`.
- R9. Фоновые циклы Go: ping сервера — через `power.Stretch`; traffic-history — гейт deep-pause по образцу снапшотов.
- R10. Фронт: поллер туннеля ProfileDrawer — только при открытом дровере; devices MonitorPage 5с→15с; ProxyPage — один поллер вместо двух; `/api/versions` 10с→60с.
- R11. Удалить маршруты `/api/logs/clear`, `/api/zapret/install` (api.js + бэкенд-биндинги) и 3 осиротевших i18n-ключа (`status.noData`, `settings.svcHint`, `settings.svcNoDataHint`).
