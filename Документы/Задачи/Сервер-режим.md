# Задача: Режим «Сервер» — туннель вместо zapret, ключи, подписки, обновления, телеметрия

## Суть

Альтернативный zapret режим: туннель **VLESS + Reality** (маскировка под TLS к сайту из «белого списка» РКН) до собственного сервера пользователя. Клиент в ZPUI — внешний `xray.exe` (паттерн `internal/zapret`), серверная часть — 4 docker-узла в папке `server/` репозитория.

## Серверная часть (`server/`, узлы независимы, можно разнести)

- **control** (`server/control/`) — Go-API + SQLite: регистрация/вход (код на почту), ключи (1 ключ = 1 устройство), подписки (тарифы 1/3/5 устр. — 50/100/150 ₽/мес; квартал −10%, год −20%), одноразовые промокоды, заявки на оплату (полуручная оплата: СБП/карта → «Я оплатил» → админ подтверждает), телеметрия, манифест обновлений ZPUI, регистрация нод.
- **node** (`server/node/`) — Xray VLESS+Reality на :443 + агент: регистрируется на control по node-токену, раз в 30с забирает клиентов (hot-reload xray), автономен при недоступности control. `NODE_CAPACITY_USERS` — ёмкость.
- **backup** (`server/backup/`) — cron-ежедневный дамп SQLite + установщики → `/backups` + опц. сетевая папка (`BACKUP_REMOTE_DIR`), `restore.sh`.
- **mail** (`server/mail/`) — Stalwart: коды регистрации и уведомления; fallback — внешний SMTP через `SMTP_*` в `.env`.

### Ёмкость
Control суммирует ёмкости нод. При исчерпании оформление подписки отклоняется **до оплаты** (`no_free_slots` → «нет свободных мест, попробуйте позже/обратитесь в поддержку»), случай пишется в `events` и уходит письмом админу (`admin_email`, настраивается в админке).

### Админ-панель (`server/control/api/web/index.html`, только Tailscale/RFC1918/loopback + `X-Admin-Token`)
Обзор+события, ёмкость и ноды (статус, онлайн, CPU, смена SNI), пользователи/устройства/ключи, заявки на оплату, промокоды (генерация пачкой, удаление, одноразовость), публикация обновлений ZPUI, телеметрия, настройки (email админа, реквизиты, интервал телеметрии).
ЛК пользователя: `lk.html` (веб) — вход/регистрация, устройства/ключи, статус подписки, покупка (тариф+период), промокод.

## Клиент ZPUI (статус)

**Готово:**
- `internal/config`: `ServerConfig` (url, key, mode, telemetry, uuid/sni/publicKey/short_id/node_addr, account) + `Get/SetServerConfig`, дефолты.
- `internal/tunnel`: менеджер xray.exe (статусы, expected/onCrash, конфиг из параметров активации, `executil.HiddenCmd`).
- `internal/app/app_server.go`: `GetServerStatus`, `SetServerSettings` (простые типы), `ServerActivate` (сбор device_id/MAC/hostname/OS), `ServerSetMode("zapret"|"server")` (стоп/старт движков через opGen+zapretExpected), `serverZPUIVersion`, opt-in `serverTelemetryLoop` (пауза в экономном режиме).
- Обновления: приоритет **server → Яндекс.Диск** в `checkUpdatesOnStartup` (GitHub остался для zapret).
- `web/src/api.js`: `/api/server/status|settings|activate|mode`; настройки: секция «Сервер ZPUI» (url, ключ, активировать, тумблер телеметрии, статус); i18n ru/en.
