# 03. Секции данных

## 1. Общие правила

- Все поля — **snake_case** (сервер сегодня парсит снапшоты в snake_case — правило из `generator.go`).
- В каждом payload — `collected_at` (RFC3339, момент сбора на устройстве).
- Живые данные помечаются `live: true/false` (`false` = приложение закрыто, отдаётся
  last-known из кеша; возраст виден по `collected_at`).
- **Дифф-секции** (`data.availability`, `data.events`, `data.errors`) — по клиентскому
  курсору: курсор в флагах БД устройства, сдвигается только после `ok`; сервер в `ack`
  возвращает подтверждённый курсор (`cursor_ack`).
- **Секции «по изменению»** (`data.config`, `data.exclusions`, `data.versions`,
  `data.operator`) — устройство держит локальный хеш/версию, отправляет только при смене.
- **За тик не более 1–2 секций** (порядок — по старшинству просрочки).
- **Состав данных жёстко зашит**: устройство не имеет операции для чего-либо вне каталога.
  Сервер физически не может запросить несуществующую секцию.

## 2. Каталог

| Операция | Что внутри | Частота | Источник на устройстве | Режим хранения |
|---|---|---|---|---|
| `data.status` | присутствие, app_running, служба, режим | 60 с (тик) | служба zsvc | upsert |
| `data.runtime` | движок, службы, порты, ТГ-мост, IP | 5 мин + при смене | кеш приложения | upsert |
| `data.availability` | история доступности (дифф) | 30 мин | служба из SQLite | поток, TTL 30д |
| `data.network` | пинг/скорость (Интернетметр) | 30 мин | служба из SQLite | upsert + поток 30д |
| `data.strategies` | баллы стратегий + игровые | 1 ч | служба из SQLite | поток, TTL 90д |
| `data.traffic` | суммы/пики трафика | 1 ч | служба из SQLite | upsert |
| `data.operator` | оператор, ASN, известные | 6 ч / при смене | служба из SQLite | upsert |
| `data.errors` | ошибки журнала (окно) | 6 ч | служба из SQLite | поток, TTL 30д |
| `data.events` | журнал действий + auth (дифф) | 6 ч | служба из SQLite | поток, TTL 90д |
| `data.system` | ОС, CPU, RAM, питание, самоизмерение | 24 ч | служба + SQLite | upsert + поток 14д |
| `data.versions` | ZPUI/zapret/компоненты | 24 ч / при смене | служба (файлы + SQLite) | upsert |
| `data.config` | анонимизированный снапшот настроек | при смене (хеш) | служба из config.json | upsert |
| `data.exclusions` | скип-лист пользователя + версия системного | при смене | служба из файлов | replace |

## 3. Форматы

**`data.status`** (~100 Б — основной heartbeat):
```json
{"app_running": true, "watch": "watching", "power_saving": false,
 "zpui_version": "2.0.4.2", "service_version": "1.4",
 "uptime_sec": 86400, "last_exit_kind": "crash", "crash_count": 2,
 "collected_at": "2026-10-23T12:00:00+03:00"}
```
`app_running`/`watch`/`last_exit_kind`/`crash_count` — из zsvc (статусы `StatusWatching`
и `ExitKind` уже есть в `internal/zsvc/config.go`).

**`data.runtime`**:
```json
{"zapret": "running", "strategy": "general3", "zapret_uptime_sec": 3600,
 "tgproxy": {"running": true, "port": 1080, "active_conn": 4, "bytes_in": 0, "bytes_out": 0},
 "socks": {"running": false, "port": 7788}, "xbox_dns": false,
 "public_ip": "1.2.3.4", "local_ips": ["192.168.1.5"],
 "live": true, "collected_at": "..."}
```

**`data.availability`** (дифф):
```json
{"cursor": "2026-10-23T11:30:00Z",
 "rows": [{"ts": "...", "kind": "monitor", "ok": 3, "total": 4, "pct": 75.0}]}
```
Ответ сервера: `{"ack": {"cursor_ack": "..."}}` — курсор сдвигается только после него.
При пачке после офлайна — прореживание (как `downsample` в `generator.go`).

**`data.network`**:
```json
{"latest": {"at": "...", "ping_ms": 24, "speed_mbps": 87.4},
 "rows": [{"at": "...", "ping_ms": 26, "speed_mbps": 85.1}]}
```

**`data.strategies`**:
```json
{"operator_key": "rostelecom",
 "rows": [{"strategy": "general3", "availability": 92.5, "use_count": 12,
           "source": "autotest", "last_applied": "...", "active": true}],
 "games": [{"strategy": "general3", "score": 78, "ping_ms": 31, "ok": 9, "total": 10}]}
```
Источник — `operator_strategies` + `strategy_games` (сегодня это `telemetryStrategyResults`/
`telemetryGameResults` в `app_telemetry.go` — переиспользовать сбор, сменить транспорт).

**`data.operator`**:
```json
{"operator": {"key": "...", "name": "Ростелеком", "asn": "12389", "isp": "...", "city": "..."},
 "known": [{"key": "...", "first_seen": "...", "last_seen": "..."}]}
```

**`data.errors`**:
```json
{"cursor": "...", "limit": 200,
 "rows": [{"ts": "...", "level": "error", "source": "updater_logs", "message": "..."}]}
```

**`data.events`**:
```json
{"cursor": "...",

```

**`data.system`**:
```json
{"os": "...", "cpu": "...", "cores": 8, "ram_total_mb": 16384,

```

**`data.versions`**:
```json
{"zpui": "2.0.4.2", "zapret": "1.10.4", "arch": "amd64",
 "components": [{"id": "tgproxy", "installed": "1.3.0", "remote": "1.3.2", "stale": false}]}
```

**`data.config`**:
```json
{"hash": "sha256:...",
 "settings": {"theme": "dark", "language": "ru",
   "auto_switch": {"enabled": true, "threshold": 60, "interval": 10},
   "proxy": {"enabled": false, "port": 7788, "has_auth": true},
   "dns": {...}, "tgproxy": {"enabled": true, "port": 1080, "fake_tls": true},
   "autostart": true, "power_saving": false}}
```
Состав — текущий `ConfigSnapshot` из `generator.go` (анонимизированный: `has_auth`,
не креды). Хеш считается от сериализованных settings.

**`data.exclusions`**:
```json
{"skip_user": "# причина\nexample.com\n...", "skip_sys_version": 42}
```

## 4. `sync.pull` — скачивание

Замена download-части `state.sync` (сегодня: `v5StateSyncData` в `app_v5.go:157`):

```json
{"exclusions": {"version": 43, "items": [...]},
 "dns_providers": {"version": 7, "items": [...]},
 "recommended": {"zpui": {"version": "2.0.5", "url": "...", "sha256": "..."},
                  "zapret": {"version": "1.10.4", "url": "...", "sha256": "..."}},
 "requests": {"now": ["diagnostics"], "skips": true}}
```

- `exclusions`/`dns_providers` — курсоры `have` как сейчас (`app_v5.go:215-219`, `dnsSyncOnce`).
- `recommended` — control plane обновлений (см. 05).
- `requests` — разовые просьбы, расширение существующего `Request`-блока
  (`app_v5.go:163-167`, обработка в `:236`): список секций + флаг скипов; исполнение —
  отправка соответствующей `data.*` на ближайшем тике. Частота исполнения просьб —
  не чаще 1 раза в час на секцию (гейт как у `skips_request_sent_at`).

## 5. Границы каталога (что НИКОГДА не передаём)

Секреты всех видов (токен аккаунта, пароли, TOTP, ключи); учётные данные прокси
(только факт `has_auth`); содержимое трафика и DNS-запросов; полные логи (только окна
с лимитами и уровнем); пути пользователя; список установленных программ; всё, что не
вошло в каталог §2. Устройство не имеет операции для чего-либо вне каталога — это и есть
граница приватности.

## 6. Пробы по требованию (этап 2, вне минимального скоупа)

`sync.requests.probe` — сервер просит прогнать blockcheck по хосту / мини-тест стратегии;
исполняет приложение (если запущено; иначе служба отвечает «невозможно»).
