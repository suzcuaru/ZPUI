# Выбор движка при запуске (zapret / zapret2), скачивание запретов приложением, приписка ZP2

> Директива владельца 13.11.2026: при запуске — модалка выбора запрета (+/− каждого),
> система ставит выбранный; запрет УБИРАЕТСЯ из обновлятора и установщика — приложение
> скачивает его само; выбор запоминается; стратегии zapret2 уходят на сервер с припиской
> «ZP2 » перед именем (сервер видит их как другие стратегии, без правок на сервере).
> Частично откатывает итерацию 5 (zapret2 в пакетах) и итерацию 3-снос (канал zapret2
> возвращается в изменённом виде). Бекап: keep-pre-zapret2-20261112.

## Проблема

Движки zapret1 и zapret2 взаимоисключающи по требованиям (WinDivert 1.4 работает при
включённой HVCI, WinDivert 2.2 — нет) и по форматам стратегий. Решение за пользователем
при первом запуске; дистрибутив не должен тащить оба запрета (вес + жёсткая связь версий).

## Цель

Пользователь при запуске выбирает движок (карточки с плюсами/минусами), приложение
скачивает выбранный дистрибутив и ставит его; выбор сохраняется в config.json;
на сервер стратегии zapret2 уходят с префиксом «ZP2 ».

## Требования

- R1. config.zapret_engine: "" | "zapret" | "zapret2"; помнится между запусками.
- R2. Модалка выбора на стартовом экране — когда движок ещё не выбран (config пуст)
  ИЛИ папка запрета отсутствует/невалидна. Карточки: ZAPRET (Flowseal) и ZAPRET 2,
  у каждой список плюсов и минусов (i18n), выбор = установка с прогрессом.
- R3. Установка выбранного движка приложением:
  - zapret — существующий канал (сервер → Яндекс → GitHub, InstallFromZip);
  - zapret2 — серверное зеркало /updates/zapret2 (архив апстрима tar.gz/zip с
    binaries/windows-x86_64) + встроенный в приложение overlay ZPUI (пресеты,
    lua-слой ZPUI, списки, fake, windivert.filter) через go:embed; version.txt.
- R4. Запрет убран из payload установщика и обновлятора (build.bat + гарды как до
    итерации 5); overlay упаковывается build'ом в internal/zapret/assets.
- R5. Смена движка позже: строка «Движок запрета» в настройках ZAPRET открывает ту же
    модалку; повторная установка выбирает правильный шаблон custom-стратегии и
    снимает несовместимый guard (InstallFromZip/legacy).
- R6. Приписка ZP2: все исходящие на сервер имена стратегий при движке zapret2
    получают префикс «ZP2 » (данные по операторам, сэмплы game-фильтра, активная
    стратегия, результаты замеров); входящие с сервера имена с префиксом
    нормализуются обратно (strip) там же, где читаются.
- R7. Status: поле engine (факт) + selected (config) для UI.
- R8. Старая миграция legacy→zapret2 в pkginst демонтируется (запрета в пакетах нет).
- R9. HVCI-диагностика (R-000-HVCI) сохраняется — актуальна для выбравших zapret2.

## Не-цели

- Авто-переключение движков, одновременная работа двух движков.
- Серверные правки (префикс — клиентская конвенция).

## Критерии приёмки

- A1. Свежая установка: модалка выбора показывается; выбор zapret2 качает архив
  с сервера (SHA), собирает zapret\ (winws2 + lua + overlay), пишет version.txt.
- A2. Выбор zapret качает legacy-архив существующим каналом и ставит службу.
- A3. После выбора и перезапуска модалка не показывается (config.zapret_engine).
- A4. На zapret2 телеметрия отдаёт «ZP2 <имя>»; на zapret — без префикса; входящие
  «ZP2 x» нормализуются.
- A5. Payload Setup/Update не содержат zapret (гард сборки); overlay в assets.
- A6. Строка «Движок запрета» в настройках открывает модалку, переключение
  переустанавливает движок и службу.
- A7. go vet/test, npm build/test, build.bat — зелёные.

## План

- internal/config: ZapretEngine + Get/Set.
- internal/zapret2 (возврат): Check/Download + InstallDist (архив→bin/windows-x86_64,
  overlay из embed, version.txt, сохранение user-списков).
- internal/zapret: ServerStrategyName/NormalizeServerStrategyName; guard InstallFromZip
  по выбранному движку.
- internal/app: биндинги GetZapretEngine/SetZapretEngine (set = установка), ZP2-префикс
  в syncclient/game-samples/active-strategy.
- build.bat: rmdir zapret из обоих payload + исходный zapret-free гард + упаковка
  overlay.zip в internal/zapret/assets.
- pkginst: демонтаж generation-aware миграции (payZapret2/legacyZapretDir).
- Фронт: StartupScreen шаг выбора (EnginePickerModal), Settings строка «Движок»,
  i18n ru/en.
- Справка: обновить раздел ZAPRET 2 (выбор движка).
