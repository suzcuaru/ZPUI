# Обмен клиента ZPUI с сервером

Что, как, когда клиент отправляет и получает. Актуально для Ресурсов 2.0 / DNS 2.0 (21.10.2026).

## Каналы

| Канал | Транспорт | Авторизация | Когда |
|---|---|---|---|
| `state.sync` | POST `/api/v5`, JSON, gzip | токен сессии | старт приложения + раз в час (`power.Stretch`) |
| `dns.providers` | POST `/api` (v4 XML) | не нужна (публичный) | в цикле синка (см. выше), до гейта подписки |
| `report.upload` | POST `/api`, multipart | отпечаток устройства (id+MAC) | старт +15 с, далее раз в telemetry-интервал (360 мин, мин. 30), максимум раз в час; также после автоподбора и вручную |
| `telemetry.push` | POST `/api` (v4 XML ≤32 КБ) | отпечаток устройства | каждый такт телеметрии (тот же интервал, без отчёта) |
| `exclusions.report` | POST `/api` (v4 XML) | отпечаток устройства | по событию: домен NXDOMAIN 3 прогона подряд; ручное добавление исключения |
| `account.*`, `device.register`, `tunnel.get`, `captcha.new` | v4 XML | по операции | действия пользователя |

## Что отправляем

- **`state.sync`**: `{dev, auth, have:{exclusions, resources}}` — версии наборов, которые у клиента уже есть. Ответ: `banned`, `account`, `subscription`, `exclusions:{version, items}` (только при активной подписке; блок не пришёл — файл не трогаем).
- **`dns.providers`** (без авторизации): `{dev}`. Ответ: `dns@version` + список `<p id name doh blocked reason><ip/></p>`.
- **`report.upload`**: `meta` (XML-конверт op=report.upload + device) и `snapshot` (JSON ≤1 МБ): статистика доступности, `resource_daily`, сеть/оператор, DNS-блок, `exclusions.user` (домены), **`skip_user`** (сырое содержимое `skip-resources.txt` с комментариями-причинами), **`skip_sys_version`** (версия системного скип-файла у клиента), стратегии, действия, логи ошибок. Части `file` — тот же отчёт в JSON-файле на сервер.
- **`telemetry.push`**: версии, ISP, сеть, стратегии, баннеры, ошибки.
- **`exclusions.report`**: до 100 доменов-кандидатов в мёртвые.

## Что получаем и куда пишем

- **Системный скип-лист** (`exclusions` из `state.sync`): при смене `version` файл `skip-resources-system.txt` (рядом с config.json) заменяется **целиком** — источники: ручные записи CRM (`skip_system.source='manual'`) + подтверждённые мёртвые домены (`'auto'`). Версия — флаг `exclusions_version` в локальной БД.
- **Системный список DNS**: при смене `dns@version` файл `dns-system.json` (рядом с config.json) заменяется **целиком** — убрали провайдера на сервере, у клиента он исчезнет после синка. Записи с `blocked="true"` остаются в файле: их нельзя включить, UI показывает подсказку «Отключён сервером по причине нестабильности». Версия — флаг `dns_system_version`.
- **Пользовательские DNS** — `dns-user.json` (мигрировали из config.json, источник истины — файл; пишется при каждом сохранении конфига).
- **Отчёт/телеметрия** — ответ нам ничего не меняет, только приём сервером.
- Оба файла (dns-system.json, dns-user.json) и скип-файлы переживают установку/обновление (`pkginst.protectedUserRel`).

## Локальные проверки (без сервера)

- **Ресурсы** (`startResourceMonitor`): первый прогон через 10 с, далее раз в `resource_check_interval` (10 мин, 30 в энергосбережении) — цели `zapret/lists/list-general.txt` + `list-general-user.txt` минус скип-листы; результаты в локальную БД (в отчёт — как `resource_daily`), NXDOMAIN ×3 → авто-добавление в `skip-resources.txt` (секция «# auto: …») + `exclusions.report`.
- **DNS** (`startDnsWatch`): первый цикл через 20 с, далее по тому же интервалу; итог цикла — в лог (`"dns": "health check: X/Y servers responded"`), 2 неудачи подряд при включённом DNS — авто-отключение с событием `xboxdns:auto_disabled`. Плюс 5-минутный watchdog починки применения.

## Установленные файлы (что где лежит)

```
<exe>\config.json                 — конфиг (пользовательские флаги провайдеров, Custom мигрировал в dns-user.json)
<exe>\dns-system.json             — системный список DNS (ведёт сервер, заменяется целиком)
<exe>\dns-user.json               — пользовательские DNS-записи (источник истины — файл)
<exe>\skip-resources.txt          — пользовательский скип-лист (секции auto/manual, правится в UI)
<exe>\skip-resources-system.txt   — системный скип-лист (ведёт сервер, заменяется целиком)
<exe>\zapret\lists\*.txt          — хост-листы движка (дистрибутив + user-файлы), ipset-all.txt — авто-скачивание
```
