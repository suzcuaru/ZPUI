## v1.5.5

Первый публичный релиз ZPUI! Простое и мощное приложение для обхода блокировок Discord, YouTube и других ресурсов на Windows.

### Добавлено

- Новый интерфейс на React 18 с тёмной темой — всё управление в одном окне
- Умный автоподбор стратегии (AutoSelect) — программа сама тестирует и выбирает лучший вариант обхода для вашего провайдера
- Встроенный SOCKS5-прокси для раздачи обхода на телефоны, планшеты и Smart TV по домашней сети
- DNS для Xbox и консолей — специальные настройки для стабильной работы игровых платформ
- Живой мониторинг с графиками скорости и списком подключённых устройств
- Мастер первого запуска с пошаговой настройкой
- Автообновление приложения и компонентов
- Встроенная диагностика для быстрого поиска проблем
- Полностью переработанная система сборки с CI/CD на GitHub Actions
- Система модулей (selfupdate, report, security)
