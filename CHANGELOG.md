# CHANGELOG

## v2.0.8

### Кратко
- Исправлена ошибка проверки ресурсов: сайты, которые на самом деле открываются, больше не отображаются как неработающие.
- Диалоговые окна открываются приятнее: фон размывается сразу, а само окно появляется следом — как у журнала.
- В фильтре стратегий добавлен отдельный тир D: слабые стратегии скрываются и показываются независимо от тира C.
- Программа больше не падает при выключении Telegram-прокси.
- Чистая установка снова автоматически ставит запрет; если что-то не подошло, сообщение теперь объясняет причину.
- При первом запуске на чистой системе снова запускается полный подбор стратегий.
- Автозапуск с Windows больше не теряется после переустановки программы.
- На экране первого запуска видно, сколько стратегий проверено и сколько времени прошло — прогресс больше не «замирает».
- Ошибки Telegram-прокси теперь по-русски.

## v2.0.7

### Кратко
- Программа стала заметно быстрее: запуск и открытие вкладок — сразу, без «загрузок» и подвисаний.
- Окна и переключение вкладок открываются плавнее — без рывков в момент появления; возврат на вкладку сохраняет её состояние и прокрутку.
- На слабых машинах и при отсутствии аппаратного ускорения интерфейс сам включает упрощённый режим (без «стекла» и лишних анимаций), чтобы не тормозить.
- Результаты проверки ресурсов появляются на графике сразу по мере готовности — без ожидания конца проверки.
- Включение и переключение DNS показывает прогресс прямо в переключателе и больше не замораживает программу; зашифрованные DNS (DoH) включаются быстрее.
- Меньше нагрузки на компьютер: убраны скрытые фоновые пересчёты — плавнее работает после запуска и в трее.
- Автосмена стратегии теперь действительно работает: при устойчивом падении сама включает лучшую стратегию и присылает уведомление.
- Тумблер «Оптимизация пинга» в фильтрах запрета — снижает задержку в сетевых играх.
- Своя стратегия «ZPUI SMART»: собрана из лучших проверенных настроек, обновляется сама.
- Прокси для домашних устройств: включается сам при запуске и недоступен чужим сетям.
- Игровой подбор сам находит лучшие порты; свои диапазоны можно задать кнопкой «Порты».
- Telegram-мост обновлён (1.11.3): стабильнее на сетях с блокировками, отвечает мгновенно, больше настроек.
- Умный подбор: без лимитов на кандидатов, учитывает скорость вашего интернета, честный итог, кнопка «Полный прогон».
- Кнопка «История» — видно, какие данные и когда уходили на сервер.
- Безопасность и надёжность: диагностика для поддержки без ваших ключей, настройки не повреждаются при сбое питания, удаление не трогает чужие данные, прокси закрыт от внешних сетей.
- Исправлено несколько десятков ошибок: зависания запуска и закрытия, обрывы графика, ложная смена стратегии при пропаже интернета, медленная вкладка DNS и другие.

- Скачивание запрета: основной источник — сервер управления, фолбэк — GitHub; добавлена кнопка установки Git одной кнопкой.
- Системный скип-лист обновляется у всех зарегистрированных устройств; пользовательские списки переживают любые установки и обновления.
- Системные списки: приписки в пользовательских списках убраны, поле быстрого добавления домена убрано (правка списка напрямую).

- В отчёты добавлены секции «Фоновые модули» и «Служба»; обновлятор больше не содержит запрет.

## v2.0.4

### Кратко
- Умный подбор переписан: рейтинг стратегий вашего оператора с сервера, проверка лучших (порог 70), применение лучшей; локальная история больше не останавливает перебор на первой же стратегии.
- Вкладка DNS: общий тумблер убран — каждый провайдер и запись включаются своим тумблером; у провайдеров индикаторы доступности, мёртвый источник блокируется, а потерявший все серверы выключается сам с уведомлением.
- Статический IP — только вручную и только на вкладке DNS; при смене сети снимается сам, предупреждение — только на ноутбуках. SOCKS5-прокси выключен по умолчанию и включается тумблером (для включения нужен статический IP).
- Режимы IPSet больше не трогают скачанный список адресов; устранено падение приложения после действий с IPSet и смены стратегий.
- Провайдер узнаётся по номеру сети, а не по названию: имя больше не «мигает», разноречивые варианты одного оператора (включая Дом.ру) склеиваются.
- Интерфейс больше не зависает под нагрузкой: база данных без общей очереди, подвисшие запросы к бэкенду перестают блокировать окно навсегда.
- Экран «Бэкенд недоступен» сам перепроверяет связь и перезапускает приложение, если офлайн длится дольше 15 секунд; тексты без служебных кодов; перезапуск больше не разворачивает окно из трея.
- Списки ресурсов разделены: системный (обновляется с сервера, только просмотр; в базе — банки и госструктуры) и пользовательский; мёртвые домены автоматически исключаются из проверок и подбора.
- Пользовательские списки запрета переживают установку, обновление и переустановку (копия возвращается после запуска); «Переустановить запрет» работает офлайн из сохранённого архива; чистая переустановка не откатывает запрет новее комплектного.
- Обновление приложения больше не содержит запрет и не трогает его — запрет ставится только установщиком.
- Игровой режим включается на любой стратегии (с предупреждением, если у стратегии нет игрового балла).
- После установки запрета приложение само прогоняет диагностику стартового экрана: критичные проблемы показываются модалкой с кнопками «Пропустить» и «Выключить запрет».
- В отчёты добавлены данные DNS и версия набора ресурсов; отчёты отправляются чаще (при запуске, после подбора, раз в час).
- Настройки Telegram-прокси переехали в сворачиваемый блок внутри своей панели.
