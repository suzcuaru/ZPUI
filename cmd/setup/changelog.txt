# CHANGELOG

## v2.1.3

### Кратко
- Новое окно «Браузерный плагин»: расширение для браузеров (Chrome, Edge, Яндекс Браузер, Opera, Brave, Vivaldi) находит заблокированные ресурсы сайта, добавляет их в обход одной кнопкой и проверяет, что заработало. Там же — пульт программы прямо в браузере: стратегия, движок, DNS и прокси.
- Плагин ставит и обновляет сама программа: выбираете браузеры (где уже стоит — выбраны сами) и жмёте «Установить». После перезапуска браузера расширение нужно включить один раз — кнопка «Включить» открывает нужную страницу.
- Отдельный установщик плагина (ZPUI-Extension-Setup): можно скачать с сайта и поставить без программы или обновить одним запуском. Программа обновляет плагин этим же установщиком автоматически.
- Само расширение ничего не обходит — оно работает только вместе с программой. Подключается по ключу из окна «MCP».
- Исправлено: установщик программы не клал пакет плагина в папку программы, поэтому окно плагина и настройки показывали «Пакет плагина не найден». Теперь пакет ставится вместе с программой, а если его там нет — программа берёт пакет отдельного установщика.
- Установка и обновление плагина идут через общее окно с прогрессом (скачивание → установка → готово) — и из окна плагина, и из настроек. По окончании окно пишет, в какие браузеры поставили, и напоминает включить плагин.
- Список браузеров и их выбор видны и без пакета: отметить браузеры и нажать «Скачать и установить» можно сразу.
- Окно плагина различает состояния в самом браузере: «включён», «выключен — включите на карточке» и «ждёт перезапуска браузера». Выключенный плагин считается установленным, его версия видна.
- Новая иконка расширения: скругленная фиолетовая плитка с буквой «Z» — читается даже в маленьком размере на панели браузера.
- Плагин подключается к программе сам: больше не нужно открывать окно «MCP» и вставлять ключ. Программа узнаёт свой плагин и пускает его на локальный сервер; при установке плагина сервер включается сам. Ключ остался в настройках плагина, в «Дополнительно», как запасной путь.
- Окно плагина переработано: сверху — карточка текущего сайта с одной главной кнопкой «Проверить», под ней список найденного и «Добавить в обход». Видно ход проверки по шагам, а после добавления — кнопка «Обновить страницу».
- В окне плагина: состояние движка бейджем, стратегия с оценкой и доступностью, квадратные тумблеры DNS и прокси, трафик со скоростью и доступностью ресурсов за сутки. Светлая и тёмная тема — по системе.
- Окно плагина больше не прокручивается: три вкладки — «Сайт», «Пульт», «Списки». В «Пульте» добавлены прокси для Telegram (вкл/выкл), проверка любого адреса с типом блокировки и графики доступности за сутки. В «Списках» виден свой список обхода: адрес можно добавить или убрать.
- ZPUI теперь распространяется по свободной лицензии MIT: код можно использовать, изменять и распространять, в том числе в коммерческих проектах.
- Найденные на сайте адреса добавляются в обход сами, без отметки вручную. Это выключается в настройках плагина.
- Плагин обновляется сам: если в приложении есть версия новее, в окне плагина появляется «Обновление», и плагин просит приложение его обновить.
- Окно «Браузерный плагин» предлагает «Обновить в браузерах», когда в браузерах стоит пакет старше текущего.
- В окне «MCP» агентам и расширению доступны работа с личным списком обхода и проверка заблокированных ресурсов.
- Балл активной стратегии теперь обновляется после каждой проверки ресурсов — панель показывает актуальные показатели, а не замеры прошлого подбора.
- Автоподбор теперь измеряет стратегию только после её фактического включения — баллы соответствуют реальной работе.
- Во время подбора стратегий провалы переходных состояний больше не попадают на график доступности.
- Программа при запуске подчищает свой временный мусор (установщики обновлений, архивы запрета, файлы старых версий).
- Проверка стратегии по правому клику теперь запускается с первого раза, а окно проверки оформлено в едином стиле с окном подбора.
- Кнопка оформления тарифа активна только когда для тарифа указана ссылка на оплату.
- Из вкладки Запрета убрана подвкладка Lua — она больше не нужна.
- На первом запуске проценты больше не замирают: видно ход настройки, ошибки показываются под прогрессом, а при подборе стратегий — какая проверяется и сколько осталось.
- Основные ресурсы теперь одинаковые на всех компьютерах.
- В полном тесте подбора стратегии выстраиваются по баллу — лидер сверху.
- Исправлено: после истечения сессии аккаунта программа больше не засыпала сервер бесконечными запросами, а честно показывает «Требуется вход» в углу окна.
- Слишком большие пакеты диагностики больше не отклоняются сервером — они аккуратно ужимаются до допустимого размера.
- Стартовый экран больше не дёргается: прогресс и название всегда на своих местах, а подробности — в отдельных строках под ними.
- В списках запрета заголовки больше не прокручиваются вместе со списком, а вкладка прокси выровнена по ширине с другими вкладками.
- Окно истории запросов переработано: последние запросы сервера — на виду, история — рядом, колонки больше не съезжают.
- Окна MCP и очистки кеша оформлены в едином стиле с остальными окнами.
- В окне подбора версия прогона переехала в заголовок (с читаемой датой), список плана свёрнут по умолчанию — разворачивается по клику.
- Ключевые ресурсы снова формируются из листов запрета (обновляются вместе с запретом) и не задваиваются.

## v2.1.0

### Кратко
- Возвращён прежний рабочий движок запрета (zapret 1) со всем набором стратегий.
- При первом запуске движок обхода скачивается автоматически — мастер настройки больше не нужен.
- Служба программы теперь следит за движком и сама его поднимает, если он остановился.
- Если служба движка падает, Windows сам перезапускает её через минуту — обход продолжает работать.
- На 32-битных Windows ставится 32-битный движок (раньше мог поставиться нерабочий 64-битный).
- Обновление запрета и переустановка при сбое — в один клик.
- Убраны всплывающие уведомления Windows о доступных обновлениях — всё видно в панели «Обновления».
- Стартовый экран стал лаконичным: только прогресс с процентами и короткие сообщения о подготовке системы.
- Загрузка и установка движка показывается так же красиво, как при обновлении программы.
- Программа иногда вежливо просит поставить звезду проекту на GitHub — не чаще раза в неделю, можно пропустить. Поддержать проект материально можно подпиской на Boosty — она в профиле пользователя.
- В тарифах подписки больше нет пометки «текущий» и безлимитов: у каждого тарифа — число устройств и описание.
- Появилась кнопка MCP в боковой панели: можно разрешить ИИ-агенту (например, ZCode или Claude) управлять программой — скопируйте готовый конфиг из окна и отдайте его агенту.
- Агент умеет смотреть статус, включать и выключать обход, менять стратегии, запускать подбор, управлять DNS и прокси и читать журнал. По умолчанию доступ выключен — включается в окне MCP.
- В справке появился раздел про MCP и ИИ-агентов: как подключить, что доступно и как это защищено.
- Вкладка «Сеть» стала вкладкой «DNS»: остались только настройки DNS — списки и фильтры живут на вкладке ZAPRET.
- Панель журнала на вкладке «Данные и диагностика» больше не съезжает и не перекрывает разделы. В журнал истории запросов добавлены фильтр (все / сервер / устройство) и счётчик записей.
- Окно MCP стало шире — конфиг и подключения помещаются без прокруток.
- В панели «Обновления» появился выбор источника: Авто, ZPUI Live, Яндекс Диск, GitHub или Гитхаб-прокси. Из выбранного источника обновляются и программа, и запреты; в «Авто» приоритет у ZPUI Live.
- Запрет обновляется вместе с программой.

## v2.0.9

### Кратко
- В фильтре стратегий по умолчанию показаны только проверенные тиры A и B.
- Ваш выбор в фильтре стратегий больше не сбрасывается — в том числе после переустановки программы.
- Окно вспомогательного Telegram-прокси больше не появляется при запуске программы.
- «Запуск свёрнутым» теперь работает: при старте окно не открывается, программа тихо ждёт в трее.
- При автозапуске вместе с Windows окно сразу показывает данные — закрывать и открывать его заново больше не нужно.
- После установки и обновления программа тоже учитывает настройку «Запуск свёрнутым».
- Отмена подбора теперь действительно останавливает проверку стратегий.
- Во время подбора автосмена и замер доступности не мешают: график оживает через несколько секунд после выбора лучшей стратегии.
- Результаты стратегий теперь соответствуют последнему подбору: свежий прогон обновляет данные, непроверенные честно помечены, отрезанные фильтром получают низкий ранг.
- Если стратегии не проверялись больше недели, программа сама предложит запустить подбор.
- DNS больше не пропадает из системы после перезапуска программы — при старте он включается сам.
- Статические DNS теперь записываются только на IPv4 и никогда не попадают на IPv6; ошибка прошлых версий на адаптерах лечится автоматически.
- Экономный режим усилен: реже обновляются данные на экранах и фоновые задачи — заметная экономия батареи.
- Надписи в панели Запрета приведены к единому виду.
- Развёрнутая боковая панель стала компактнее — больше места для содержимого.
- Линии на графике доступности дотягиваются до правого края — график больше не выглядит оборванным.
- Панель статуса Запрета выровнена по размерам с остальными карточками.
- Все статус-панели (Запрет, DNS, Прокси) приведены к одному образцу: одинаковые отступы, высота и скругления.
- Статические DNS и провайдеры теперь взаимоисключающие: включение одного честно выключает другое, без мигания индикаторов и «залипших» тумблеров.
- DNS больше не пропадает из системы при включении и выключении статических серверов: при их отключении возвращаются ранее включённые провайдеры.
- Выключение «Статический IP вместо DHCP» больше не сбрасывает применённые DNS-серверы — они остаются на адаптере.
- Если DNS-серверы всё же не удалось применить — тумблер DNS честно выключается сам и программа сообщает об этом, а не притворяется включённым.
- Подбор стратегий показывает финальный шаг «Проверка доступности» — конец проверки больше не проходит незаметно.
- Проверка доступности в подборе меряется в тех же условиях, что и на главном экране, — проценты сопоставимы.
- Тумблеры DNS-серверов при применении показывают колесо загрузки — как остальные тумблеры.
- Название DNS-провайдера больше не белеет на зелёном состоянии — цвет честно показывает живость.
- Тумблеры при небыстрых действиях показывают spin-индикатор, кнопки приведены к единому образцу с разными размерами.
- Проверка стратегий стала заметно точнее: скорость и пинг меряются с прогревом и без помех от фоновых задач — цифры соответствуют реальности (проверка идёт дольше, это цена точности).
- Балл стратегии теперь сравнивается с вашим прямым каналом: перед подбором система замеряет скорость и пинг без обхода, и чем ближе стратегия к этой скорости — тем выше балл.
- Установка запрета с сервера больше не ломается на новых архивах: обязательными считаются только файлы движка, списки программа создаёт сама.
- Галочки в установщике теперь хорошо видны на всех экранах.
- График доступности обновляется сразу после окончания проверки — без перехода между вкладками.
- Подсказки при наведении возвращены у всех кнопок боковой панели.
- Уточнены формулировки в подсказках и сообщениях об ошибках.
- Программа стала «легче»: убраны неиспользуемые внутренние функции, снижена фоновая активность.
- Сайт проекта и свежие версии: [zpui-life.ru](https://zpui-life.ru)

## v2.0.7

### Кратко
- Программа стала заметно быстрее: запуск и открытие вкладок — сразу, без «загрузок» и подвисаний.
- Окна и переключение вкладок открываются плавнее — без рывков в момент появления; возврат на вкладку сохраняет её состояние и прокрутку.
- На слабых машинах и при отсутствии аппаратного ускорения интерфейс сам включает упрощённый режим (без «стекла» и лишних анимаций), чтобы не тормозить.
- Результаты проверки ресурсов появляются на графике сразу по мере готовности — без ожидания конца проверки.
- Включение и переключение DNS показывает прогресс прямо в переключателе и больше не замораживает программу; зашифрованные DNS (DoH) включаются быстрее.
- Меньше нагрузки на компьютер: убраны скрытые фоновые пересчёты — плавнее работает после запуска и в трее.
- Автосмена стратегии теперь действительно работает: при устойчивом падении сама включает лучшую стратегию и присылает уведомление.
- Тумблер «Оптимизация пинга» в фильтрах запрета — снижает задержку в сетевых играх.
- Своя стратегия «ZPUI SMART»: собрана из лучших проверенных настроек, обновляется сама.
- Прокси для домашних устройств: включается сам при запуске и недоступен чужим сетям.
- Игровой подбор сам находит лучшие порты; свои диапазоны можно задать кнопкой «Порты».
- Telegram-мост обновлён (1.11.3): стабильнее на сетях с блокировками, отвечает мгновенно, больше настроек.
- Умный подбор: без лимитов на кандидатов, учитывает скорость вашего интернета, честный итог, кнопка «Полный прогон».
- Кнопка «История» — видно, какие данные и когда уходили на сервер.
- Безопасность и надёжность: диагностика для поддержки без ваших ключей, настройки не повреждаются при сбое питания, удаление не трогает чужие данные, прокси закрыт от внешних сетей.
- Исправлено несколько десятков ошибок: зависания запуска и закрытия, обрывы графика, ложная смена стратегии при пропаже интернета, медленная вкладка DNS и другие.

## v2.0.5

### Кратко
- Автоподбор переработан: два режима — «Умный» (доступен всем, работает даже без сервера) и «Игровой» с выбором стратегий; ход показывается конвейером фаз, виден провайдер.
- Появилась служба ZPUI: следит за приложением, автоматически восстанавливает его после сбоя, ведёт свой журнал (подвкладка в журнале).
- Автозапуск с Windows переделан на стандартную схему: запись видна в Диспетчере задач и управляется оттуда; тумблер больше не «откатывается».
- Приложение стало устойчивее к сбоям: фоновые модули перезапускаются сами, повторяющиеся уведомления не спамят, настройка адресов DNS не «зависает» в системе.
- Запрет стал живучее: страховочная копия рядом с приложением, восстановление списков после установки, самодиагностика файлов до старта движка, сброс зависшего драйвера без полной переустановки.
- Скачивание запрета: основной источник — сервер управления, фолбэк — GitHub; добавлена кнопка установки Git одной кнопкой.
- Системный скип-лист обновляется у всех зарегистрированных устройств; пользовательские списки переживают любые установки и обновления.
- Системные списки: приписки в пользовательских списках убраны, поле быстрого добавления домена убрано (правка списка напрямую).
- Починено: запуск запрета с системным скип-листом, пропавший список Google, дубли доменов, «Применена стратегия», спам восстановления запрета при запуске, чип провайдера, журнал службы, остановка прокси, спецсимволы в пути установки, проверка контрольных сумм обновлений.
- В отчёты добавлены секции «Фоновые модули» и «Служба»; обновлятор больше не содержит запрет.

## v2.0.4

### Кратко
- Умный подбор переписан: рейтинг стратегий вашего оператора с сервера, проверка лучших (порог 70), применение лучшей; локальная история больше не останавливает перебор на первой же стратегии.
- Вкладка DNS: общий тумблер убран — каждый провайдер и запись включаются своим тумблером; у провайдеров индикаторы доступности, мёртвый источник блокируется, а потерявший все серверы выключается сам с уведомлением.
- Статический IP — только вручную и только на вкладке DNS; при смене сети снимается сам, предупреждение — только на ноутбуках. SOCKS5-прокси выключен по умолчанию и включается тумблером (для включения нужен статический IP).
- Режимы IPSet больше не трогают скачанный список адресов; устранено падение приложения после действий с IPSet и смены стратегий.
- Провайдер узнаётся по номеру сети, а не по названию: имя больше не «мигает», разноречивые варианты одного оператора (включая Дом.ру) склеиваются.
- Интерфейс больше не зависает под нагрузкой: база данных без общей очереди, подвисшие запросы к бэкенду перестают блокировать окно навсегда.
- Экран «Бэкенд недоступен» сам перепроверяет связь и перезапускает приложение, если офлайн длится дольше 15 секунд; тексты без служебных кодов; перезапуск больше не разворачивает окно из трея.
- Списки ресурсов разделены: системный (обновляется с сервера, только просмотр; в базе — банки и госструктуры) и пользовательский; мёртвые домены автоматически исключаются из проверок и подбора.
- Пользовательские списки запрета переживают установку, обновление и переустановку (копия возвращается после запуска); «Переустановить запрет» работает офлайн из сохранённого архива; чистая переустановка не откатывает запрет новее комплектного.
- Обновление приложения больше не содержит запрет и не трогает его — запрет ставится только установщиком.
- Игровой режим включается на любой стратегии (с предупреждением, если у стратегии нет игрового балла).
- После установки запрета приложение само прогоняет диагностику стартового экрана: критичные проблемы показываются модалкой с кнопками «Пропустить» и «Выключить запрет».
- В отчёты добавлены данные DNS и версия набора ресурсов; отчёты отправляются чаще (при запуске, после подбора, раз в час).
- Настройки Telegram-прокси переехали в сворачиваемый блок внутри своей панели.
