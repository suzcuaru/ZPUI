# Отладка ZPUI

## Где смотреть первыми

1. **Логи приложения:** `internal/logger` пишет через `slog` в файл; журнал дублируется в SQLite (`internal/logdb`, таблицы по категориям). Читать: API `/api/logs`, `/api/logs/tables`, `/api/logs/find` (`internal/app/app_api_logs.go`) или напрямую файлы логов.
2. **Лог сборки:** `dist/build-<версия>.log` — если проблема воспроизводится после сборки.
3. **Диагностический отчёт:** `internal/reports` + модуль `cmd/report` (report.exe) — собирает сведения о системе, конфиг, логи. Пользователю, который не может объяснить проблему, проси отчёт через UI.
4. **Состояние движка:** `internal/zapret` — конечный автомат stopped/starting/running/error/restarting; лимит 5 рестартов за 60 сек → `error`. Восстановление никогда не должно отключаться (`zapretExpected`) — если движок «сам выключился», ищи в recovery-логике `internal/app/app_recovery.go`.

## Ловушки Wails (частые причины «зависло/пусто»)

- **Весь UI замер** — биндинг выполняется синхронно дольше ~5 сек. Лечение: долгую операцию делать асинхронной (горутина + `EventsEmit` прогресса, либо запуск + отдельный `GetXxxResult` с поллингом ~2с и таймаутом 120с).
- **Map-параметр приходит пустым** — `map[string]interface{}` в биндинге из JS не наполняется. Лечение: простые типизированные параметры (строки/числа/були).
- **Событие не долетело** — `EventsEmit` с составными payload тоже теряется; слать простую структуру или флаг.
- **Настройка «слетела» после перезапуска** — поле добавлено только в `GetConfig()`, но не в `SetConfig()` (для `notify_*` — `SetNotifyFlags()`). Единственный источник истины — `config.json`.

## Ловушки React

- **Серый экран** — хук вызван на module scope (вне компонента), React падает до рендера. Диагностика: `npm run dev`/`vite preview` + `window.onerror`. Также помогает no-store для assetserver против кэша WebView2.
- **Контекстное меню закрывается до клика** — document-level `mousedown` срабатывает раньше `click`; нужны `stopPropagation` + проверка `closest()`.
- **Функция «не видит» свежий prop** — stale closure: `useCallback` без prop в deps.
- **`createStream`/query-параметры** — query разбирается внутри через `parseQuery`; ветки `_tryStart` матчатся по base-пути (без query), иначе матчинг ломается.

## Проверка гипотез

- Точечная проверка стратегии zapret — ПКМ по стратегии (тест только её) через AutoSelectAndApply с `onlyStrategy`.
- tgproxy — живой E2E только под флагом `ZPUI_TG_E2E`; WS-мост ходит только через DC2/DC4.
- Мониторинг/доступность: YouTube-проверка (ytcheck, DNS vs DoH + TLS) сознательно НЕ входит в % доступности и AutoSwitch — не «чинить» это.
- Экономный режим (`internal/power`): замедленные интервалы и приостановка фона — не баг, а режим; статус отдаёт `/api/status`.

## Известные незакрытые расхождения

- Ретеншн логов: пользователь требовал 7 дней, в коде (`CleanOld`) пока 30 — при работе с логами помни о задаче.

После исправления — полный прогон: `go vet ./...`, `go test ./...`, `cd web && npm run build`, затем `cmd //c build.bat`. Изменения фиксируй в `CHANGELOG.md` (секция текущей версии).
