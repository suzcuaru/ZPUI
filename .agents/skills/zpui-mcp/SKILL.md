# Управление ZPUI через MCP

## Что это

ZPUI — настольное приложение для Windows, одним переключателем включающее обход
блокировок (Discord, YouTube и др.) через движок zapret. Дополнительно: SOCKS5-прокси
и Xbox DNS для раздачи обхода в домашнюю сеть, мост Telegram-прокси.

Встроенный MCP-сервер (Model Context Protocol, streamable HTTP) даёт ИИ-агенту
(ZCode, Claude Desktop и т. п.) те же ответы, что видит UI приложения.

## Подключение

1. Пользователь включает сервер: ZPUI → сайдбар → **MCP** → тумблер. По умолчанию выключен.
2. Сервер слушает **только 127.0.0.1**, доступ по Bearer-ключу.
3. URL: `http://127.0.0.1:<порт>/mcp`, порт по умолчанию **8930**. Если порт занят,
   сервер сам сдвигается на +10 (до 10 попыток) и сохраняет выбранный в config.json —
   берите актуальный порт из модалки MCP, а не из старого конфига.
4. Ключ (32 hex) — в модалке MCP; там же готовый JSON-конфиг для клиента (кнопка
   «Копировать»). Регенерация ключа мгновенно убивает все текущие сессии агентов.

Пример конфига клиента:

```json
{
  "mcpServers": {
    "zpui": {
      "url": "http://127.0.0.1:8930/mcp",
      "headers": { "Authorization": "Bearer <ключ из модалки MCP>" }
    }
  }
}
```

Этот файл скилла лежит в папке установки: `<папка ZPUI>\skills\zpui-mcp\SKILL.md`.
Программа поддерживает его актуальным сама (переписывает при обновлении).

## Инструменты (15)

**Чтение — безопасны:**

| Инструмент | Аргументы | Что возвращает |
|---|---|---|
| `get_status` | — | Полный статус: движок zapret, SOCKS, DNS, мост Telegram, версия, хост, батарея/эконом, сетевые метрики |
| `list_strategies` | — | Список стратегий с пометкой `current:true` и замерами (score/availability/grade/ping/speed) |
| `get_availability` | `hours` (1–720, дефолт 24) | История доступности по группам `standard` (34 ресурса), `key` (17 ключевых), `user` (пользовательские); записи раз в 10 минут, `pct` = процент живых |
| `get_logs` | `lines` (дефолт 50, макс 500) | Хвост журнала по таблицам: `app_logs`, `updater_logs`, `zapret_logs`, `tgproxy_logs` |
| `get_user_list` | — | Пользовательский список обхода: `{hosts:[...], count}` (`list-general-user.txt`) |
| `get_socks_status` | — | Статус SOCKS5-прокси: `enabled`, `running`, `port`, `static_ip` |
| `check_resource` | `url` | Диагностика блокировки URL: `report.Blocked`, `report.BlockType` (тип блокировки), `report.InUserList`, послойно `Direct.TCP` / `Direct.TLS` / `Direct.HTTP` |

**Действия — меняют систему пользователя (спрашивать подтверждения, если задача явным
их не требует):**

| Инструмент | Аргументы | Эффект |
|---|---|---|
| `engine_start` / `engine_stop` / `engine_restart` | — | Запуск/остановка/перезапуск обхода. `engine_stop` отключает обход — интернет в заблокированные ресурсы пропадает |
| `set_strategy` | `name` — **имя файла**, например `general (ALT13).bat` | Смена стратегии с перезапуском движка. Имя брать только из `list_strategies` (с пробелами и скобками) |
| `run_autoselect` | `mode`: `smart` (дефолт) / `full` / `game` / `startup` | Автоподбор стратегии асинхронно: сразу вернёт `{"started":true,"mode":...}`, прогресс — в UI приложения; готовность проверяй `get_status.auto_test_running` |
| `dns_enable` | `enabled` (bool) | Включить/выключить замену DNS в системе |
| `proxy_enable` | `enabled` (bool) | Включить/выключить локальный SOCKS5-прокси (порт 1080) |
| `add_user_hosts` | `hosts` (массив строк) | Добавить домены в пользовательский список обхода → `{status, added, skipped}`. Движок перечитывает список сам, рестарт не нужен. Только домены: буквы, цифры, точки, дефисы, префикс `^` |

## Формат ответов

- Успех: `{"status":"ok", ...данные}` (поля данных рядом со status).
- Ошибка операции: `{"error":"текст"}` — проверяй наличие поля `error` в каждом ответе.
- Неизвестный инструмент / плохие аргументы — JSON-RPC error транспортного уровня.

## Ключевые поля `get_status`

- `zapret.status` — одно из `stopped / starting / running / error / restarting`.
  `error` после серии падений: смотри `get_logs` (таблица `zapret_logs`).
- `zapret.strategy` — активная стратегия (имя файла без `.bat`), `zapret.version` — версия движка.
- `zapret.service_installed` — движок живёт как служба Windows.
- `tg_proxy.status` + `tg_proxy.stats` — мост Telegram (общее/плохие соединения, ws_errors).
- `xbox_dns.enabled/applied` — DNS-раздача на Xbox.
- `mod.version` — версия самого ZPUI; `power_saving` — экономный режим (фоновые такты растянуты).
- `monitor.download_fmt / upload_fmt` — текущая скорость сети.

## Типовые сценарии

1. **«Работает ли обход?»** — `get_status` → `zapret.status` + `get_availability` (последние
   записи `key.pct`). 100% — всё живо; ниже 70 — `list_strategies` и предложить подбор.
2. **Диагностика жалобы** — `get_status` → `get_logs` (200–300 строк) → искать ERROR/WARN
   по категориям `zapret`, `dns`, `proxy`, `mcp`.
3. **Смена стратегии** — `list_strategies` → выбрать по score/availability → `set_strategy`
   → через 5–10 с `get_status` убедиться, что `status=running` и стратегия сменилась.
4. **Подбор лучшей** — `run_autoselect` (smart), ждать завершения (автотест гаснет),
   потом `get_status.zapret.strategy` + замеры из `list_strategies`.

## Ловушки

- MCP выключен по умолчанию и недоступен, пока пользователь не включил тумблер
  (или ZPUI не запущен). Транспортная ошибка подключения = «попроси пользователя
  включить MCP в модалке», а не ретрай-шторм.
- Порт мог сдвинуться (+10) — не хардкодь 8930, бери из модалки/конфига.
- `set_strategy` ждёт **имя файла** (`general (ALT13).bat`), а `get_status` возвращает
  короткое имя (`general (ALT13)`) — для обратной смены собери имя файла из `list_strategies`.
- Скорости в `monitor` — человекочитаемые строки (`4.01 KB/s`), числа — в `*_speed` (байт/с).
- Стратегии без замеров приходят без полей score/availability — это норма, не ошибка.
- Действия с движком видны в UI мгновенно: пользователь смотрит на тот же экран.
  Не выполняй `engine_stop`/`set_strategy`/`dns_enable` без явной просьбы пользователя.
